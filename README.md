# Tejidos Alana 🧶

Sitio web One Page para **Tejidos Alana**, emprendimiento de tejidos artesanales hechos a mano en Katira de Guatuso, Costa Rica.

## 📋 Descripción

Tejidos Alana ofrece:
- 🗝️ Llaveros artesanales
- 💻 Fundas para laptop
- 📚 Accesorios para escuela y oficina
- 🏠 Decoraciones para el hogar

## 🎨 Identidad

- **Nombre:** Tejidos Alana
- **Eslogan:** "Hecho a mano, pensado para ti"
- **Frase inspiradora:** "Las manos son la herramienta de la mente." — María Montessori

### Paleta de colores

| Color | Hex | Uso |
|-------|-----|-----|
| Marrón profundo | `#5C3D2E` | Textos y títulos |
| Marrón medio | `#8B6B4F` | Elementos secundarios |
| Terracota | `#C67A4E` | Acentos y botones |
| Crema | `#FFF9F0` | Fondo principal |
| Beige cálido | `#F5E6D3` | Secciones alternas |

## 🛠️ Tecnologías

- HTML5 semántico (sin `<div>`)
- CSS3 con variables y anidamiento nativo
- Flexbox y CSS Grid
- Responsive (mobile-first)
- JavaScript moderno (Semana 3)
